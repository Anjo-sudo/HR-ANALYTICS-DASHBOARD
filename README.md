HR Analytics Dashboard

An interactive HR Analytics Dashboard built using Power BI to analyze employee data, workforce trends, and organizational performance. This dashboard helps HR teams make data-driven decisions by providing meaningful insights into employee attrition, performance, attendance, and department-wise analysis.

✨ Features
Employee Attrition Analysis
Department-wise Employee Distribution
Attendance & Performance Tracking
Gender Diversity Insights
Salary & Experience Analysis
Interactive Filters & Slicers
KPI Monitoring Dashboard
Data Visualization & Business Insights
📊 Tools & Technologies Used
Power BI
Excel / CSV Dataset
Data Cleaning & Transformation
DAX Functions
Data Visualization Techniques
📌 Dashboard Insights
Identified departments with higher attrition rates
Analyzed employee performance trends
Compared salary distribution across departments
Tracked employee attendance and engagement
Improved HR decision-making through visual analytics
🎯 Objective

The main objective of this project is to transform raw HR data into actionable insights that help organizations improve employee retention, productivity, and workforce management.
